# AI Assistance Disclosure

## Purpose

AI tools were used as development assistants for the DATAKGP hackathon
project. They supported implementation and documentation work but were not
used as a substitute for experimental verification.

## Areas where AI assistance was used

AI assistance contributed to:
- project architecture and component planning;
- implementation suggestions for the Python backend and React/TypeScript
  frontend;
- debugging hypotheses and code-level troubleshooting;
- README and technical-report drafting;
- experiment and evaluation planning;
- preparation of demonstration material;
- preparation of project diagrams and other presentation assets.

## Human verification

The project was reviewed and executed by the project team. In particular,
implementation changes were tested locally, the controlled evaluation was
executed from the repository, and the resulting CSV was inspected and
aggregated before the reported result was included in the documentation.

The final project therefore distinguishes between:
1. AI-assisted development and drafting; and
2. experimentally verified project results.

## Experimental evidence

The controlled benchmark result reported by this project was produced by the
repository's evaluation code. The final reported result is:

**360 / 360 exact matches (100% exact-match rate)**

under the explicitly documented controlled benchmark configuration.

This result is scoped only to the self-generated benchmark and is not a claim
of ARC-AGI performance, official BDH-CQ performance, or Pathway performance.

## No fabricated evidence

AI-generated text, code suggestions, or proposed results were not accepted as
experimental evidence without execution or inspection. Where an earlier
implementation produced misleading benchmark behavior, the implementation was
debugged and the benchmark was rerun before the final result was documented.

## Attribution

The repository's source code, experiments, documentation, and conclusions
remain the responsibility of the project team. AI assistance does not imply
ownership, endorsement, or authorship by any AI provider.
