# Sources, Licenses, and Reused Materials

## 1. Project scope

This repository is an independent educational/research artifact inspired by
publicly documented ideas associated with BDH and BDH-CQ. It is **not** the
Pathway production implementation and does not claim to reproduce proprietary
continual-learning, infinite-context, or internal benchmark systems.

The implementation in this repository contains both:
- mechanisms motivated by public research descriptions; and
- original experimental mechanisms introduced for this hackathon project.

Claims about this project are scoped to the code, experiments, and controlled
benchmarks contained in this repository.

## 2. Primary research references

### BDH

The Dragon Hatchling: The Missing Link between the Transformer and Models of
the Brain (2025).

arXiv: https://arxiv.org/abs/2509.26507

The paper motivates biologically inspired alternatives involving sparse
activations, local interactions, and recurrent/associative memory mechanisms.
The project uses these public research ideas as inspiration rather than
claiming a full reproduction.

### BDH-CQ

BDH-CQ: In-Context Learning with Recurrent Latent Reasoning (2026).

arXiv: https://arxiv.org/abs/2608.09888

The paper motivates recurrent latent computation in which information from
the input can update recurrent state and reasoning can occur without exposing
a natural-language chain of thought. The project's latent reasoning and
telemetry mechanisms are simplified experimental implementations and should
not be interpreted as the paper's full system.

### Titans

Titans: Learning to Memorize at Test Time (2025).

arXiv: https://arxiv.org/abs/2501.00663

Used as background context for test-time/fast memory and associative-memory
ideas.

### Hungry Hungry Hippos

Hungry Hungry Hippos: Towards Language Modeling with State Space Models
(2022).

arXiv: https://arxiv.org/abs/2212.14052

Used as background context for recurrent/state-space approaches to sequence
modeling.

## 5. Data and benchmark generation

The controlled evaluation reported in the technical report uses
self-generated synthetic ARC-style tasks implemented in the repository.

Current controlled benchmark scope:
- 3 task families
- 2 memory modes
- 3 reasoning depths
- 20 seeds per configuration
- 5x5 grids
- 3 demonstrations per episode
- 360 total episodes

No claim is made that this benchmark is equivalent to ARC-AGI or any official
Pathway benchmark.

## 8. AI-assisted development disclosure

AI tools were used during development as an assistance mechanism for:
- architecture and experiment planning;
- code drafting and refactoring;
- debugging and interpretation of implementation errors;
- documentation and README drafting;
- technical report drafting/editing;
- generation of prompts and project presentation material;
- preparation of project diagrams/visual assets.

Human review, execution, testing, debugging, and final project decisions were
used to validate the implementation. AI-generated suggestions were not treated
as experimental evidence.

The reported benchmark values were obtained by executing the project's
evaluation code; they were not generated by an AI model as claimed results.

## 9. Reproducibility and scientific integrity

All quantitative claims in the submission should be traceable to repository
code, stored result files, or explicitly labeled controlled experiments.

In particular, the reported 100% exact-match result means 360/360 exact matches
on the project's controlled generated benchmark. It must not be presented as
ARC-AGI performance, Pathway performance, or a reproduction of proprietary
results.
